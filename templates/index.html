nbidal18 v4.1.2-packwiz

This is the updater-enabled Prism Launcher edition of nbidal18 4.1.2.

Download the Prism instance

  1. Open Prism Launcher.
  2. Select Add Instance, then Import.
  3. Choose the downloaded ZIP.
  4. Click Play. The first launch downloads the complete pack; later launches download only updates.

The client and server must report the same pack version through Better Compatibility Checker.
